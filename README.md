## Specification

Binary outcome: 1 = no-show, 0 = checked-in. All seven available predictors are eligible. A CART classification tree uses Gini impurity, maximum depth 3, minimum 15 training appointments per leaf, and random seed 42. These settings were fixed before inspecting test results, to keep the tree small and avoid tiny leaves. No scaling or imputation is needed: all features are numeric and complete. No class weighting or cost-based threshold adjustment is used. The assignment's decision is the tree's majority-class prediction.

A stratified random split with seed 42 allocates 280 rows to training (64 no-shows, 22.86%) and 120 to testing (27 no-shows, 22.50%). The complete dataset has 400 rows, 8 columns, and 91 no-shows (22.75%). Nothing is fitted on the test set. This is one reasonable prespecified model, not a claim that it is globally optimal.

## Tree interpretation

Root: prior_no_shows <= 2.5. Patients with 3 or more previous no-shows are predicted no-show. For 0–2 previous no-shows, the next split is whether an SMS reminder was sent. Without an SMS, the tree splits again at prior_no_shows <= 0.5: no previous misses means hold, while 1–2 means overbook. With an SMS, it splits at prior_no_shows <= 1.5, but both resulting leaves predict show.

Thus the tree's complete majority-class policy simplifies to: overbook if prior_no_shows >= 3, OR if sms_reminder == 0 and prior_no_shows >= 1; otherwise hold. The actual prediction function uses the fitted model, not a separately hand-coded approximation. Lead time, age, distance, new-patient status, and appointment hour were eligible but not used in splits. These are predictive associations; the tree does not establish that sending an SMS causes attendance.

D: root <= 2.5 -> sms_reminder <= 0.5 -> prior_no_shows > 0.5 -> leaf 4 -> overbook. This leaf contains 29 no-shows and 23 shows in training.

E: root <= 2.5 -> sms_reminder > 0.5 -> prior_no_shows <= 1.5 -> leaf 6 -> hold. This leaf contains 5 no-shows and 134 shows in training. Leaf identifiers are scikit-learn's zero-based node IDs and match the tree image.

## Economics

Baseline: -120 × 27 = -$3,240.

v1: -60 × 7 FP -120 × 7 FN = -$1,260.

Savings: 120 × 20 recovered no-shows -60 × 7 overbooked shows = $1,980 across 120 test appointments, or $16.50 per appointment. This reduces modeled losses by 61.11%.

Assume 10,000 appointments per year. Baseline projected value is -$270,000/year; tree projected value is -$105,000/year; projected savings are $165,000/year. These are scenario projections, not measured yearly profits. They assume the test mix continues, replacement patients fill missed appointments as specified, and the supplied costs capture the consequences. A cautious operational recommendation is a monitored pilot, given the small retrospective test set and seven double-arrival cases.

The economic break-even no-show probability is 1/3: overbook loss is 60(1-p), hold loss is 120p. The assigned majority-class policy uses a 0.5 boundary; no alternative policy was fitted or evaluated here.
